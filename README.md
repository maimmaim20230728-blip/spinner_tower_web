# スゴロクタワー / Spinner Tower（Web版）

ルーレットを回して塔をのぼる、縦型分岐すごろく。分かれ道を選び、カードを集めて、頂上の宝箱に**ぴったり**止まった人が勝ち。

**完全無料・広告なし・登録不要・オフラインOK**

介護と支援の相談どころ「そよぎ」 https://soudansoyogi.com/

## あそびかた
- ルーレットを回して、出た数だけ塔をのぼる
- 分かれ道はタップで選ぶ（敵のいない安全な道か、報酬のある道か）
- コイン・ダイヤ・カードを集める。カードは持つだけで効くものと、使うと効くものがある
- 頂上の宝箱には**ぴったり**止まらないと入れない。ストップカードで調整しよう

## モード
- **対戦（AI）** … 14段の塔を順にクリアして解放
- **みんなで** … 2〜4人でスマホを交代。AIも混ぜられる
- **ソロ無限のぼり** … 体力が続く限りどこまでも。50/100/200/500階で称号

## 技術
物理エンジン・画像素材・重いAIなし。単一 `index.html` + Web Audio 生成音 + SVGドット絵。

Farcaster Mini App 対応。
